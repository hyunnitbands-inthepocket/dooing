# dooing

오늘 할 일과 일정, 한 달 캘린더를 한 화면에서 보는 웹 플래너입니다. 빌드 과정 없이 `index.html` 하나로 동작합니다.

## 기능

- **오늘 박스**: 오늘 일정(시간순, all day 맨 위)과 카테고리별 할 일
- **월간 캘린더**: 일정 보기 / 할 일 보기 전환, 일정 시간 한 줄·정사각형 표시
- **추가**: 날짜를 누르면 할 일·일정 2분할 버튼, 일정은 all day와 매주·매달·매년 반복 지원
- **할 일 옮기기·복사**: 캘린더에서 꾹 눌러 끌어 옮기기, 한 번 눌러 복사 후 날짜에 붙여넣기 (폰은 날짜 창의 버튼으로)
- **한국 달력**: 공휴일·대체공휴일 자동 계산, 음력 1일·보름 표시
- **마이페이지**: 프로필, 일정·할 일 카테고리 이름과 색 편집, 화면 모드

## 실행

`index.html`을 브라우저로 열면 됩니다. 데이터는 브라우저의 localStorage에만 저장됩니다.
