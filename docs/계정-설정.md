# dooing 로그인 켜기 (Supabase)

로그인 기능은 코드에 들어가 있고, Supabase 주소와 공개 키를 넣으면 켜집니다. 아래 순서대로 하면 돼요.

## 1. Supabase 프로젝트 만들기

1. https://supabase.com 에 가입하고 **New project**를 누릅니다.
2. 이름은 `harupan`, 리전은 **Northeast Asia (Seoul)**을 고릅니다. 데이터베이스 비밀번호는 따로 잘 보관하세요(앱에는 안 씁니다).
3. 만들어지면 **Project Settings → API**에서 두 가지를 복사합니다.
   - **Project URL** (`https://xxxx.supabase.co`)
   - **anon public** 키
   - ⚠️ `service_role` 키는 절대 공유하거나 코드에 넣지 마세요.

## 2. 데이터베이스 표 만들기

1. 왼쪽 메뉴 **SQL Editor → New query**
2. 저장소의 `supabase/schema.sql` 내용을 통째로 붙여넣고 **Run**
3. 사용자마다 자기 데이터만 보이게 막는 규칙과 회원 탈퇴 기능이 같이 만들어집니다.

## 3. 돌아올 주소 등록

**Authentication → URL Configuration**

- **Site URL**: `https://hyunnitbands-inthepocket.github.io/harupan/`
- **Redirect URLs**에 추가:
  - `https://hyunnitbands-inthepocket.github.io/harupan/**`
  - `http://localhost:5180/**` (내 컴퓨터에서 미리볼 때)

## 4. 이메일 로그인

**Authentication → Providers → Email**이 켜져 있으면 끝입니다. 이메일을 넣으면 로그인 링크가 가고, 처음이면 그때 바로 가입됩니다.

> 무료 플랜의 기본 메일 발송은 한 시간에 몇 통으로 제한돼 있어요. 사용자가 늘면 **Authentication → SMTP Settings**에서 메일 발송 서비스를 연결하세요.

## 5. Google 로그인

1. https://console.cloud.google.com → 프로젝트 만들기 → **API 및 서비스 → OAuth 동의 화면** 설정(외부, 앱 이름 "dooing")
2. **사용자 인증 정보 → OAuth 클라이언트 ID 만들기 → 웹 애플리케이션**
   - 승인된 리디렉션 URI: `https://xxxx.supabase.co/auth/v1/callback` (xxxx는 내 Supabase 주소)
3. 나온 **클라이언트 ID**와 **클라이언트 보안 비밀번호**를 Supabase **Authentication → Providers → Google**에 넣고 켭니다.

## 6. 카카오 로그인

1. https://developers.kakao.com → **내 애플리케이션 → 애플리케이션 추가하기** (앱 이름 "dooing")
2. **앱 키**에서 **REST API 키**를 복사합니다.
3. **제품 설정 → 카카오 로그인**: 활성화 **ON**, Redirect URI에 `https://xxxx.supabase.co/auth/v1/callback` 등록
4. **제품 설정 → 카카오 로그인 → 보안**: Client Secret 코드를 만들고 **사용함**으로 바꾼 뒤 복사
5. **동의항목**: 닉네임, 프로필 사진, **카카오계정(이메일)**을 설정합니다.
   - 이메일 동의항목은 **비즈 앱**이어야 열립니다. 앱 설정 → 비즈니스에서 개인 개발자로 비즈 앱 전환을 하세요.
6. Supabase **Authentication → Providers → Kakao**에 REST API 키(Client ID)와 Client Secret을 넣고 켭니다.

## 7. 앱에 키 넣기

Project URL과 anon public 키를 Claude에게 알려 주면 `index.html`의 `CLOUD_URL`, `CLOUD_KEY`에 넣고 배포합니다.
(직접 넣는다면 `index.html`에서 `const CLOUD_URL = '';` 와 `const CLOUD_KEY = '';` 를 찾아 따옴표 안에 붙여넣으면 됩니다.)
